LEDGER – local version

Quick try on a laptop: double-click index.html (works, but cannot be installed as an app).

To install as an app on phone and laptop:
1. Upload ALL files in this folder to a free GitHub Pages site (code only; your data never goes there).
2. Open the https link on each device, then Install / Add to Home Screen.
Data is stored separately on each device until Drive sync is added.

When you edit any file later, change CACHE = 'ledger-v1' in sw.js to 'ledger-v2' so devices update.
